## 1. Описание

Программа с окном (GUI), похожая на терминал Linux.
Пользователь вводит команды, программа их выполняет и показывает результат.
В заголовке окна написано имя VFS.

Написано на Python, используется встроенный модуль tkinter.

### Этапы

- **Этап 1. REPL** — окно программы, разбор команд с кавычками,
  сообщения об ошибках, команды-заглушки `ls` и `cd`, команда `exit`.
- **Этап 2. Конфигурация** — настройки запуска (`--vfs`, `--log`,
  `--script`), вывод настроек при запуске, XML-лог команд,
  стартовый скрипт с комментариями, команда `conf-dump`.

## 2. Команды и настройки

### Команды

| Команда | Что делает |
|---|---|
| `ls` | выводит своё имя и аргументы |
| `cd` | выводит своё имя и аргумент (не больше одного) |
| `exit` | закрывает программу |
| `conf-dump` | показывает настройки в виде `ключ=значение` |

Аргументы с пробелами можно писать в кавычках: `cd "My Documents"`.

Если команда неизвестна или аргументы неверные, программа пишет ошибку.

### Настройки запуска

| Параметр | Что задаёт |
|---|---|
| `--vfs ПУТЬ` | папку VFS (её имя видно в заголовке окна) |
| `--log ФАЙЛ` | XML-файл, куда пишутся все команды с датой и временем |
| `--script ФАЙЛ` | стартовый скрипт, который выполнится сразу после запуска |

При запуске программа печатает все настройки (строки `[debug]`).

Стартовый скрипт — это текстовый файл, одна команда в строке.
Строки, начинающиеся с `#`, — комментарии. Если в скрипте ошибка,
программа пишет номер строки и останавливает скрипт.
Примеры скриптов лежат в папке `scripts`.

## 3. Запуск и тесты

```bash
./run.sh                    # запуск программы
./run.sh test               # запуск тестов
./run.sh --vfs ./myvfs --log log.xml --script scripts/start_ok.txt
```

В Windows без Git Bash: `run.bat`, `run.bat test`.

Готовые скрипты для проверки настроек: `scripts/test_*.sh`,
например `bash scripts/test_all_params.sh`.

## 4. Пример

```
user@myvfs:~$ ls -l "My Documents"
ls: аргументы ['-l', 'My Documents']
user@myvfs:~$ cd a b
cd: слишком много аргументов
user@myvfs:~$ foo
foo: команда не найдена
user@myvfs:~$ conf-dump
vfs=./myvfs
vfs_name=myvfs
log=log.xml
script=scripts/start_ok.txt
user@myvfs:~$ exit
```

Пример записи в `log.xml`:

```xml
<event>
  <datetime>2026-10-06T16:28:14</datetime>
  <command>ls</command>
  <args><arg>-l</arg></args>
  <status>ok</status>
</event>
```
